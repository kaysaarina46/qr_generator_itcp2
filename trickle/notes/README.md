# QRGen Pro - Modern QR Generator

A powerful web-based QR Code generator built with React and TailwindCSS.

## Features
- Multiple data types (URL, Text, WiFi, Email)
- Real-time preview
- Customizable colors (Dark/Light)
- Multiple size options
- High-quality downloads (PNG)
- Error correction level adjustment

## Tech Stack
- React 18
- TailwindCSS
- Lucide Static Icons
- qrcode.js library
